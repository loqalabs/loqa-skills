# Loqa Skills

Community skill templates and curated examples for the Loqa ambient intelligence platform.

## Overview

This repository contains a collection of skills, plugins, and integrations for Loqa. Skills enable Loqa to perform specific tasks, integrate with external services, and provide custom functionality.

## Categories

- **Home Automation**: Control smart home devices and services
- **Productivity**: Calendar, reminders, note-taking integrations
- **Entertainment**: Music, podcasts, media control
- **Information**: Weather, news, knowledge queries
- **Developer Tools**: Code assistance, documentation lookup
- **Custom Skills**: User-contributed skills and templates

## Contributing a Skill

We welcome community contributions! To submit a skill:

1. Fork this repository
2. Create your skill following the template structure
3. Add documentation and examples
4. Submit a pull request
